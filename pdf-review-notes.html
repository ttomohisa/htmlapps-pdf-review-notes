使い方と注意事項

    

      
      
基本操作
  1. PDFを開きます。
  2. 文章をドラッグして選択し、表示されたメニューからレビュー種別を選びます。
  3. コメントを追加すると右側のレビュー一覧へ登録されます。レビューを選ぶと該当ページ・位置へ戻れます。

      
PDFのすぐ上の「前のレビュー」「次のレビュー」で、絞り込みと並び順に沿って移動します。端では止まり、未選択時は次のレビューで先頭へ移動します。コメントの入力中は移動しません。

      
レビュー種別
修正 / 質問 / 要確認 / 良い / メモの5種類を使えます。この段階では状態管理や編集はまだありません。

      
プライバシー
PDFとレビュー内容はブラウザー内で処理され、外部サーバーへ送信されません。原本PDFも変更しません。

      
注意事項
  • 最大250 MiBです。100 MiBを超えるPDFでは端末によって処理に時間がかかる場合があります。
  • スキャン画像だけのPDFでは選択できる文章がありません。図表・画像・スキャンPDF向けの矩形レビューにも対応しています。
  • 書き出し名は同じPDFを開いている間保持されます。HTMLレポートの作成中は閉じる・Escで中止できます。
  • レビューはこの端末に自動保存され、JSONで再開できます。「保存削除」後はこのPDFを閉じるまで自動保存が停止します。必要ならJSON / Markdown / CSV / 単一HTMLへ書き出してください。
配布HTMLを直接開いて利用できます。実行時の外部通信は行いません。
